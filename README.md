# DumOS — restaurant ordering and kitchen display

A small single-outlet demo built with Node.js and browser-native JavaScript.

## Run

Requires Node.js 18 or newer.

```sh
npm test
npm start
```

Open http://localhost:3000. Checkout is simulated; no payment is collected. Orders persist in `data/orders.json` on the local filesystem. The kitchen view is a demo and has no authentication.
